# タスク12: 任意日時入力機能 - TODOリスト

## 機能概要
指定した時間の地球の回転数を表示する機能を実装します。
タブ切り替えで「現在時刻モード」と「時間指定モード」を切り替え可能にします。

## 要件
- 要件6: 任意日時入力機能の実装
  - DateTimeInput コンポーネントを作成
  - 任意の日時から地球回転数を計算する機能を実装
  - 入力バリデーションとエラーハンドリングを追加
  - UTC 基準とローカル日基準の選択機能を実装
